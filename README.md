# طريق · TRIQ

سوق مغربي للسيارات والدراجات النارية المستعملة — مبني على الشفافية بدل الإعلانات وحدها.

> **الفكرة:** المواقع الحالية كتعرض عليك إعلانات. طريق كيعطيك المعلومات اللي كتخليك
> تقرر: واش هاد البائع موثوق؟ واش هاد الثمن معقول؟ وشحال غادي تصرف على هاد المركبة فالسنة؟

---

## شنو كيميّز هاد الموقع

| الميزة | الوصف |
|---|---|
| **مؤشر الثقة** | تنقيط مستقل على ١٠٠ نقطة لكل إعلان عبر ٦ ركائز: موثوقية البائع، الوثائق القانونية، سجل المركبة، شفافية الإعلان، اتساق المعطيات، والفحص المستقل — مع تنبيهات مخاطر صريحة (كيلومتراج غير منطقي، ثمن مشبوه، وثائق ناقصة). |
| **الثمن العادل** | ثمن مرجعي محسوب من إعلانات مشابهة بعد تعديلها حسب العمر، الكيلومتراج، الحالة، الوقود والقوة — مع مجال ثقة ونسبة دقة. لما تكون المشابهات قليلة، الموقع كيقول ليك «مراجع محدودة» بدل ما يخترع رقماً. |
| **التكلفة الحقيقية** | حاسبة تجمع الفينيات (حسب القوة الجبائية والوقود)، التأمين، المحروقات، الصيانة، الإطارات، الفحص التقني وخسارة القيمة — بالدرهم في السنة، في الشهر، ولكل كيلومتر. |
| **البحث بالدارجة** | كتكتب «كليو ديزل تحت ١٢ مليون فكازا» والموقع كيفهمها ويحوّلها لفلاتر. كيتعامل مع «مليون» كوحدة ثمن مغربية، وأسماء المدن والماركات بالدارجة والفرنسية. |
| **الأثمنة بالمليون** | زر تبديل بين الدرهم و«المليون» — كيفما كيتكلمو المغاربة (١ مليون = ١٠ ٠٠٠ درهم). |
| **الفحص المستقل** | خدمة فحص من ١٢٠ نقطة كيديرها ميكانيكي ماعندو علاقة بالبائع، والتقرير كيتربط بالإعلان. |
| **المقارنة الذكية** | حتى ٣ مركبات جنب بعضياتهم، مع إبراز القيمة الأحسن في كل سطر — بما فيها التكلفة السنوية وقيمة إعادة البيع. |
| **مساعد البيع** | معالج نشر الإعلان كيبيّن ليك مؤشر الثقة ديالك كيتبنى مباشرة، مع اقتراحات مرقّمة لرفعو، وتنبيه إذا كان ثمنك بعيد على السوق. |

## التقنيات

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** مع نظام تصميم قائم على متغيرات CSS (وضع ليلي/نهاري)
- واجهة عربية RTL بالكامل، خط `IBM Plex Sans Arabic` للنصوص و`Space Grotesk` للأرقام
- **بدون صور خارجية**: كل رسوم المركبات مولّدة كـ SVG إجرائي (نقشة زليجية + ظلال حسب نوع الهيكل)
- **بدون قاعدة بيانات**: البيانات التجريبية مولّدة بشكل حتمي (نفس المدخل ⇒ نفس المخرج) لتفادي اختلاف الخادم والمتصفح
- تفضيلات المستخدم (المفضلة، المقارنة، الوحدة، الوضع) محفوظة في `localStorage`

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بناء الإنتاج (يولّد صفحة ثابتة لكل إعلان)
npm start
npm run typecheck
```

## كيف يشتغل محرك الثمن

1. كيختار الإعلانات المشابهة بوزن مركّب: نفس الموديل ← نفس الماركة ← نفس الفئة والهيكل والقوة.
2. كيعدّل ثمن كل مشابه ليصير مقارَناً بالمركبة المستهدفة:
   - **العمر** عبر منحنى احتفاظ بالقيمة (انخفاض سريع في البداية ثم يتباطأ)
   - **الكيلومتراج** بنسبة محدودة لكل شريحة
   - **الحالة**، **نوع الوقود**، **ناقل السرعة**، و**القوة/سعة المحرك**
3. كيحسب متوسطاً مرجّحاً بعد تحييد القيم الشاذة، مع مجال يعكس تشتت السوق.
4. كيقيس **الثقة** حسب قوة أقرب مشابهة وعددها والتشتت — وإذا كانت ضعيفة كيعرض
   «مراجع محدودة» بدل حكم قاطع.

## ملاحظة

هادي منصة عرض تقني: الإعلانات والبائعون والأرقام بيانات تجريبية مولّدة، ماكاينش خادم
ولا قاعدة بيانات ولا معاملات حقيقية. تعريفات الضرائب وأثمنة المحروقات إرشادية وخاصها
تتحقق من المصادر الرسمية قبل أي استعمال حقيقي.
