# النشر — خطوتين

الموقع مربوط بـVercel: **marketmaroc** (`prj_O28EIS7lsOCpdcnVd8r4RRwXiAP8`)
على مستودع `mounirbeni/Market`. كل push للفرع كينشر تلقائياً.

باقي غير شي حاجتين ماقدرتش نديرهم من بيئة التطوير (شوف «علاش» تحت).

---

## 1. بدّل password ديال Neon

الـconnection string القديم تعرّض. قبل أي شي:

**Neon → مشروعك → Roles → `neondb_owner` → Reset password**

انسخ الـ**Pooled connection string** الجديد.

## 2. زيد `DATABASE_URL` فـVercel

**Vercel → marketmaroc → Settings → Environment Variables**

| الحقل | القيمة |
|---|---|
| Name | `DATABASE_URL` |
| Value | الـconnection string الجديد |
| Environments | ✅ Production ✅ Preview ✅ Development |

من بعد: **Deployments → آخر واحد → ⋯ → Redeploy**

## 3. عمّر قاعدة البيانات (مرة وحدة)

قاعدة Neon جديدة كتجي خاوية. عندك جوج طرق:

### أ. من التيليفون — صفحة `/setup`

بعد ما تضبط `DATABASE_URL` وتنشر، حل:

    https://<الموقع>/setup

الصفحة كتوريك الحالة (الاتصال، الجداول، الهجرات، عدد الإعلانات)
وفيها زر واحد. الضغطة كتصاوب الجداول وكتعمّرها.

التعمير كيمشي على دفعات ديال 25 إعلان مع شريط تقدّم — Neon بعيد،
وكل استعلام فيه ذهاب وإياب، ف104 إعلان دفعة وحدة يقدرو يتجاوزو
الحد ديال مدة الدالة. إلا تقطعات الشبكة، عاود الضغط: كيكمّل من
فين وقف.

**الحمايات:** الهجرات idempotent (جدول `schema_migrations` كيتبّع
اللي طبّق). التعمير كيتّدار غير على قاعدة خاوية — ملي تكون كاينة
إعلانات، المسار كيرجع الأرقام وماكيكتب والو. باش تعاود الإعداد على
قاعدة عامرة، خاصك تضبط `SETUP_KEY` وتزيدو فالرابط: `/setup?key=...`

### ب. من Neon SQL Editor

`db/neon-full.sql` فيه المخطط والبيانات فملف واحد (275 كيلو).
Neon → SQL Editor → الصق → Run.

كيتّدار مرة وحدة على قاعدة خاوية — إلا كانت الجداول كاينة،
الإدراجات كيطيحو على المفاتيح المكررة.

### ج. من الحاسوب

    npm run db:setup            # هجرة + تعمير
    npm run db:migrate          # الهجرات فقط
    npm run db:migrate -- --status
    npm run db:seed -- --reset  # مسح كلشي وإعادة التعمير

بجوج الطرق كيستعملو نفس الدوال (`src/lib/db/migrate.ts` و
`src/lib/db/seed.ts`) — نسخة وحدة، ماكاينش تفرّق مع الوقت.

## إرسال الإيميل (اختياري، من بعد)

دابا رمز التحقق كيبان فالشاشة (وضع تطوير). ملي تضبط
`EMAIL_PROVIDER` فمتغيرات Vercel (Resend / Postmark / SES)، الرمز
ماكيرجعش أبداً للمتصفح — الشرط مكتوب فـ`src/lib/auth.ts`.

## الصور

الصور كتّرفع لـ**Vercel Blob** نيشان من المتصفح للخزّان — ماشي عبر
الخادم — حيت تصويرة تيليفون عادة أكبر من الحد ديال جسم الطلب فVercel
(4.5 ميغا). الخادم كيوقّع غير توكن محدود بالمستخدم وبنوع الملف وبحجمو.

**باش تفعّلها:**

1. Vercel → Storage → Blob → أنشئ خزّان (ولا استعمل اللي عندك)
2. نسخ التوكن وزيدو فـ Project → Settings → Environment Variables:
   `BLOB_READ_WRITE_TOKEN` (Production + Preview + Development)
3. نفس التوكن فـ`.env.local` للتطوير المحلي

**بلا التوكن** الموقع كيخدم عادي: معالج البيع كيبيّن رسالة واضحة
وكيخلّيك تنشر الإعلان بلا صور، والمركبة كتّرسم بالرسم المولّد.

### علاش الصور `public` ماشي `private`

الإعلان كيتشاف من أي زائر، والصور كيبانو ف24 بطاقة فصفحة النتائج.
مع `private` كل صورة خاصها تعدّى من دالة خادم — يعني 24 استدعاء
لكل صفحة، بلا CDN وبلا cache فالمتصفح. مع `public` CDN ديال Vercel
كيخدم الصور مباشرة.

إلا بغيتي شي نهار وثائق خاصة (كارط كريز مثلاً) هادوك خاصهم `private`
مع مسار خادم كيقدّمهم — بدّل `BLOB_ACCESS` فـ`src/lib/blob.ts`.

## إرسال الإيميل — واجب للدخول

الدخول برمز كيتصيفط للإيميل. **بلا مزوّد، ماكاينش دخول فالإنتاج** —
المسار كيرجع خطأ واضح بدل ما يرجع الرمز للمتصفح (اللي معناه أي واحد
كيدخل بأي إيميل).

فالتطوير المحلي ماشي محتاج والو — الرمز كيبان فالسجل وفالشاشة.

### الخيارات

| المزوّد | المجاني | الطريقة |
|---|---|---|
| **Brevo** (منصوح) | 300/يوم | HTTP API |
| Resend | 3000/شهر | HTTP API |
| SMTP عام | حسب الخادم | Gmail، Brevo SMTP، أي خادم |

**HTTP خير من SMTP فVercel**: كل استدعاء ديال دالة serverless كيفتح
اتصال TCP وTLS جديد للخادم ديال SMTP — أبطأ، وأحياناً كيتقطع.

### Brevo

brevo.com → SMTP & API → API Keys → Generate

    EMAIL_PROVIDER=brevo
    BREVO_API_KEY="xkeysib-xxx"
    EMAIL_FROM="طريق <contact@نطاقك>"

### SMTP (Gmail مثلاً)

Gmail كيطلب **كلمة سر التطبيقات**، ماشي كلمة السر العادية:
myaccount.google.com → Security → 2-Step Verification → App passwords

    EMAIL_PROVIDER=smtp
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=587
    SMTP_USER="you@gmail.com"
    SMTP_PASS="كلمة سر التطبيقات"

⚠ **حدود Gmail:** ~500 إيميل فاليوم للحساب المجاني. وGmail كيبدّل
عنوان المُرسِل لعنوان الحساب إلا ماكانش مسجّل كـ«Send mail as».
مناسب للتجريب، ماشي لسوق فيه زبناء.

### توثيق النطاق

باش الرسائل يوصلو لصندوق الوارد ماشي للـspam، وثّق نطاقك عند المزوّد
(SPF + DKIM). بلا توثيق:
· Brevo/Resend كيرفضو الإرسال من نطاق ماشي ديالك
· Resend بلا نطاق كيصيفط من `onboarding@resend.dev` — كيوصل غير
  للإيميل ديال حسابك نتا

## متغيّرات البيئة

| المتغيّر | واجب؟ | لواش |
|---|---|---|
| `DATABASE_URL` | ✅ | قاعدة البيانات. بلاها الموقع كيخدم بالبيانات المرفقة (قراءة فقط) |
| `EMAIL_PROVIDER` | ⚠ | `brevo` \| `resend` \| `smtp`. **بلاه ماكاينش دخول** |
| `BREVO_API_KEY` | ⚠ | مع `brevo` |
| `RESEND_API_KEY` | ⚠ | مع `resend` |
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` | ⚠ | مع `smtp` |
| `EMAIL_FROM` | ❌ | المُرسِل. خاصو نطاق موثّق عند المزوّد |
| `SETUP_KEY` | ❌ | كيسمح بإعادة تشغيل `/setup` على قاعدة عامرة |
| `BLOB_READ_WRITE_TOKEN` | ❌ | رفع صور الإعلانات. بلاه الموقع كيرسم المركبة |
