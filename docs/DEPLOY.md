# النشر — خطوتين

الموقع مربوط بـVercel: **marketmaroc** (`prj_O28EIS7lsOCpdcnVd8r4RRwXiAP8`)
على مستودع `mounirbeni/Market`. كل push للفرع كينشر تلقائياً.

باقي غير شي حاجتين ماقدرتش نديرهم من بيئة التطوير (شوف «علاش» تحت).

---

## 1. بدّل password ديال Neon

الـconnection string القديم تعرّض. قبل أي شي:

**Neon → مشروعك → Roles → `neondb_owner` → Reset password**

انسخ الـ**Pooled connection string** الجديد.

## 2. زيد `DATABASE_URL` فـVercel

**Vercel → marketmaroc → Settings → Environment Variables**

| الحقل | القيمة |
|---|---|
| Name | `DATABASE_URL` |
| Value | الـconnection string الجديد |
| Environments | ✅ Production ✅ Preview ✅ Development |

من بعد: **Deployments → آخر واحد → ⋯ → Redeploy**

## 3. عمّر قاعدة البيانات (مرة وحدة)

من جهازك، فمجلد المشروع:

```bash
echo 'DATABASE_URL="<الـstring الجديد>"' > .env.local
npm install
npm run db:setup
```

`db:setup` = هجرة + بذر. كيطبع:

```
→ 0001_init.sql … ✓
· 16 مستخدم
· 9 معرض
· 104 إعلان (+ سجل المركبة + تاريخ الأثمنة)
```

أوامر منفصلة إلا بغيتي:

```bash
npm run db:migrate              # المخطط فقط
npm run db:migrate -- --status  # شنو تطبّق وشنو لا
npm run db:seed                 # البيانات
npm run db:seed -- --reset      # مسح وإعادة
```

## إرسال الإيميل (اختياري، من بعد)

دابا رمز التحقق كيبان فالشاشة (وضع تطوير). ملي تضبط
`EMAIL_PROVIDER` فمتغيرات Vercel (Resend / Postmark / SES)، الرمز
ماكيرجعش أبداً للمتصفح — الشرط مكتوب فـ`src/lib/auth.ts`.

## الصور

الصور كتّرفع لـ**Vercel Blob** نيشان من المتصفح للخزّان — ماشي عبر
الخادم — حيت تصويرة تيليفون عادة أكبر من الحد ديال جسم الطلب فVercel
(4.5 ميغا). الخادم كيوقّع غير توكن محدود بالمستخدم وبنوع الملف وبحجمو.

**باش تفعّلها:**

1. Vercel → Storage → Blob → أنشئ خزّان (ولا استعمل اللي عندك)
2. نسخ التوكن وزيدو فـ Project → Settings → Environment Variables:
   `BLOB_READ_WRITE_TOKEN` (Production + Preview + Development)
3. نفس التوكن فـ`.env.local` للتطوير المحلي

**بلا التوكن** الموقع كيخدم عادي: معالج البيع كيبيّن رسالة واضحة
وكيخلّيك تنشر الإعلان بلا صور، والمركبة كتّرسم بالرسم المولّد.

### علاش الصور `public` ماشي `private`

الإعلان كيتشاف من أي زائر، والصور كيبانو ف24 بطاقة فصفحة النتائج.
مع `private` كل صورة خاصها تعدّى من دالة خادم — يعني 24 استدعاء
لكل صفحة، بلا CDN وبلا cache فالمتصفح. مع `public` CDN ديال Vercel
كيخدم الصور مباشرة.

إلا بغيتي شي نهار وثائق خاصة (كارط كريز مثلاً) هادوك خاصهم `private`
مع مسار خادم كيقدّمهم — بدّل `BLOB_ACCESS` فـ`src/lib/blob.ts`.

## متغيّرات البيئة

| المتغيّر | واجب؟ | لواش |
|---|---|---|
| `DATABASE_URL` | ✅ | قاعدة البيانات. بلاها الموقع كيخدم بالبيانات المرفقة (قراءة فقط) |
| `EMAIL_PROVIDER` | ❌ | ملي يتضبط، رمز الدخول كيتصيفط بالإيميل بدل ما يبان فالشاشة |
| `BLOB_READ_WRITE_TOKEN` | ❌ | رفع صور الإعلانات. بلاه الموقع كيرسم المركبة |
